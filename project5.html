Part 1: Sampling Loops

1.1 Implementing the Forward Process

The forward process for diffusion is defined by:

\(\begin{align} x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1 - \bar\alpha_t} \epsilon \quad \text{where}~ \epsilon \sim N(0, 1) \end{align}\)

for a given clean image \(x_0\) and noise coefficient \(\bar{\alpha}_t\) at timestep \(t\). And so I implemented this forward process as a function that takes in an image im and timestep t:


                        def forward(im, t):
                            with torch.no_grad():
                                alpha_t = alphas_cumprod[t]
                                eps = torch.randn_like(im)
                                im_noisy = torch.sqrt(alpha_t)*im + torch.sqrt(1-alpha_t)*eps
                            return im_noisy

1.4 Iterative Denoising

We can improve the one-step denoiser from Part 1.3 by implementing an iterative denoiser iterative_denoise. To save time and computational cost, I used a strided step of \(30\) starting at timestep \(990\) to denoise to timestep \(0\). At each denoising step, we use the following formula:

\(\begin{align} x_{t'} = \frac{\sqrt{\bar\alpha_{t'}}\beta_t}{1 - \bar\alpha_t} x_0 + \frac{\sqrt{\alpha_t}(1 - \bar\alpha_{t'})}{1 - \bar\alpha_t} x_t + v_\sigma \end{align}\)

where:

  • \(x_t\) is your image at timestep \(t\)
  • \(x_{t'}\) is your noisy image at timestep \(t'\) where \(t' < t\) (less noisy)
  • \(\bar\alpha_t\) is the noise coefficient at timestep \(t\)
  • \(\alpha_t = \bar\alpha_t / \bar\alpha_{t'}\)
  • \(\beta_t = 1 - \alpha_t\)
  • \(x_0\) is our current estimate of the clean image

This is what iterative_denoise looks like:


                    def iterative_denoise(im_noisy, i_start, prompt_embeds, timesteps):
                        image = im_noisy

                        with torch.no_grad():
                            for i in range(i_start, len(timesteps) - 1):
                                t = timesteps[i]
                                prev_t = timesteps[i+1]

                                alpha_cumprod = alphas_cumprod[t]
                                alpha_cumprod_prev = alphas_cumprod[prev_t]
                                alpha = alpha_cumprod / alpha_cumprod_prev
                                beta = 1 - alpha

                                model_output = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=prompt_embeds,
                                    return_dict=False
                                )[0]

                                noise_est, predicted_variance = torch.split(model_output, image.shape[1], dim=1)

                                clean_t_step = (image - torch.sqrt(1-alpha_cumprod)*noise_est) / torch.sqrt(alpha_cumprod)
                                pred_prev_image = ((torch.sqrt(alpha_cumprod_prev)*beta)/(1-alpha_cumprod))*clean_t_step 
                                                    + ((torch.sqrt(alpha)*(1-alpha_cumprod_prev))/(1-alpha_cumprod))*image
                                pred_prev_image = add_variance(predicted_variance.to('cpu'), 
                                                                torch.tensor([t]),
                                                                pred_prev_image.to('cpu'))

                                image = pred_prev_image.to(device).half()

                            clean = image.cpu().detach().numpy()

                        return clean

1.6 Classifier-Free Guidance (CFG)

In order to greatly improve image quality (at the expense of image diversity), we can use a technique called Classifier-Free Guidance. Now, we compute both a conditional noise estimate \(\epsilon_c\) and an unconditional noise estimate \(\epsilon_u\). Then, we let our new noise estimate be:

\(\begin{align} \epsilon = \epsilon_u + \gamma(\epsilon_c - \epsilon_u) \end{align}\)

where \(\gamma\) controls the strength of CFG (I used \(\gamma=7\)). To get an unconditional noise estimate, we can just pass an empty prompt embedding of "" to the diffusion model. Here is my implementation of iterative_denoise_cfg, which is almost identical to iterative_denoise:


                        def iterative_denoise_cfg(im_noisy, i_start, prompt_embeds, uncond_prompt_embeds, timesteps, scale=7):
                            image = im_noisy

                            with torch.no_grad():
                                for i in range(i_start, len(timesteps) - 1):
                                    ...

                                    model_output = stage_1.unet(
                                        image.half().to(device),
                                        t,
                                        encoder_hidden_states=prompt_embeds,
                                        return_dict=False
                                    )[0]

                                    uncond_model_output = stage_1.unet(
                                        image.half().to(device),
                                        t,
                                        encoder_hidden_states=uncond_prompt_embeds,
                                        return_dict=False
                                    )[0]

                                    noise_est, predicted_variance = torch.split(model_output, image.shape[1], dim=1)
                                    uncond_noise_est, _ = torch.split(uncond_model_output, image.shape[1], dim=1)

                                    cfg_noise_est = uncond_noise_est + scale*(noise_est - uncond_noise_est)

                                    clean_t_step = (image - torch.sqrt(1-alpha_cumprod)*cfg_noise_est) / torch.sqrt(alpha_cumprod)
                                    pred_prev_image = ((torch.sqrt(alpha_cumprod_prev)*beta)/(1-alpha_cumprod))*clean_t_step 
                                                        + ((torch.sqrt(alpha)*(1-alpha_cumprod_prev))/(1-alpha_cumprod))*image
                                    pred_prev_image = add_variance(predicted_variance.to('cpu'), 
                                                                   torch.tensor([t]), 
                                                                   pred_prev_image.to('cpu'))

                                    image = pred_prev_image.half().to(device)

                                clean = image.cpu().detach().numpy()

                            return clean

1.7.2 Inpainting

Again, we will use the same procedure to implement inpainting, i.e., given an image \(x_{\text{orig}}\), and a binary mask \(\bf{m}\), we can create a new image that has the same content where \(\bf{m}\) is \(0\), but new content wherever \(\bf{m}\) is \(1\). At every step of the diffusion denoising loop after computing \(x_t\), we "force" it to have the same pixels as \(x_{\text{orig}}\) where \(\bf m\) is 0:

\(\begin{align} x_t \leftarrow \textbf{m} x_t + (1 - \textbf{m})\text{forward}(x_{\text{orig}}, t) \end{align}\)

Here is the inpaint function that does this procedure, which is the same as iterative_denoise_cfg, except it denoises a random noise image and does the inpainting step at the end of the iterative loop:


                        def inpaint(original_image, mask, prompt_embeds, uncond_prompt_embeds, timesteps, scale=7):
                            image = torch.randn_like(original_image).to(device).half()

                            with torch.no_grad():
                                for i in range(10, len(timesteps) - 1):
                                    ...

                                    clean_t_step = (image - torch.sqrt(1-alpha_cumprod)*cfg_noise_est) / torch.sqrt(alpha_cumprod)
                                    pred_prev_image = ((torch.sqrt(alpha_cumprod_prev)*beta)/(1-alpha_cumprod))*clean_t_step 
                                                        + ((torch.sqrt(alpha)*(1-alpha_cumprod_prev))/(1-alpha_cumprod))*image
                                    pred_prev_image = add_variance(predicted_variance.to('cpu'), 
                                                                    torch.tensor([t]),
                                                                    pred_prev_image.to('cpu'))

                                    image = pred_prev_image.half().to(device)

                                    image = mask*image + (1-mask)*(forward(original_image, t).half().to(device))

                                clean = image.cpu().detach().numpy()

                            return clean

1.8 Visual Anagrams

Now, I will create Visual Anagrams with diffusion models, specifically images that look like one prompt, but another prompt flipped upside down.

To do so, I will denoise an image \(x_t\) at step \(t\) normally with the prompt \(p_1\), to obtain noise estimate \(\epsilon_1\). But at the same time, flip \(x_t\) upside down, and denoise with the prompt \(p_2\) to get noise estimate \(\epsilon_2\). Then, I flip \(\epsilon_2\) back, and average the two noise estimates. After, perform a reverse diffusion step with the averaged noise estimate. This is what make_flip_illusion looks like:


                    def make_flip_illusion(image, i_start, prompt_embeds, uncond_prompt_embeds, timesteps, scale=7):
                        prompt_embeds_1, prompt_embeds_2 = prompt_embeds[0], prompt_embeds[1]
                        uncond_prompt_embeds_1, uncond_prompt_embeds_2 = uncond_prompt_embeds[0], uncond_prompt_embeds[1]

                        with torch.no_grad():
                            for i in range(i_start, len(timesteps) - 1):
                                t = timesteps[i]
                                prev_t = timesteps[i+1]

                                alpha_cumprod = alphas_cumprod[t]
                                alpha_cumprod_prev = alphas_cumprod[prev_t]
                                alpha = alpha_cumprod / alpha_cumprod_prev
                                beta = 1 - alpha

                                model_output_1 = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=prompt_embeds_1,
                                    return_dict=False
                                )[0]

                                uncond_model_output_1 = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=uncond_prompt_embeds_1,
                                    return_dict=False
                                )[0]

                                noise_est_1, predicted_variance = torch.split(model_output_1, image.shape[1], dim=1)
                                uncond_noise_est_1, _ = torch.split(uncond_model_output_1, image.shape[1], dim=1)

                                cfg_noise_est_1 = uncond_noise_est_1 + scale*(noise_est_1 - uncond_noise_est_1)

                                flipped_image = torch.flip(image, [2])

                                model_output_2 = stage_1.unet(
                                    flipped_image.half().to(device),
                                    t,
                                    encoder_hidden_states=prompt_embeds_2,
                                    return_dict=False
                                )[0]

                                uncond_model_output_2 = stage_1.unet(
                                    flipped_image.half().to(device),
                                    t,
                                    encoder_hidden_states=uncond_prompt_embeds_2,
                                    return_dict=False
                                )[0]

                                noise_est_2, _ = torch.split(model_output_2, image.shape[1], dim=1)
                                uncond_noise_est_2, _ = torch.split(uncond_model_output_2, image.shape[1], dim=1)

                                cfg_noise_est_2 = uncond_noise_est_2 + scale*(noise_est_2 - uncond_noise_est_2)
                                cfg_noise_est_2 = torch.flip(cfg_noise_est_2, [2])

                                cfg_noise_est = (cfg_noise_est_1 + cfg_noise_est_2) / 2

                                clean_t_step = (image - torch.sqrt(1-alpha_cumprod)*cfg_noise_est) / torch.sqrt(alpha_cumprod)
                                pred_prev_image = ((torch.sqrt(alpha_cumprod_prev)*beta)/(1-alpha_cumprod))*clean_t_step 
                                                    + ((torch.sqrt(alpha)*(1-alpha_cumprod_prev))/(1-alpha_cumprod))*image
                                pred_prev_image = add_variance(predicted_variance.to('cpu'), 
                                                               torch.tensor([t]), 
                                                               pred_prev_image.to('cpu'))

                                image = pred_prev_image.half().to(device)

                            clean = image.cpu().detach().numpy()

                        return clean

1.9 Hybrid Images

In this part, I will implement Factorized Diffusion. Similar to Part 1.8, I will create a composite noise estimate \(\epsilon\) by estimating the noise with two different text prompts, and then combining low frequencies from one noise estimate with high frequencies of the other. I will use torchvision.transforms.functional.gaussian_blur with kernel size \(33\) and \(\sigma=2\) to get the low and high frequencies. Here is the make_hybrids function that does this:


                    def make_hybrids(image, i_start, prompt_embeds, uncond_prompt_embeds, timesteps, scale=7):
                        prompt_embeds_1, prompt_embeds_2 = prompt_embeds[0], prompt_embeds[1]
                        uncond_prompt_embeds_1, uncond_prompt_embeds_2 = uncond_prompt_embeds[0], uncond_prompt_embeds[1]

                        with torch.no_grad():
                            for i in range(i_start, len(timesteps) - 1):
                                ...

                                model_output_1 = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=prompt_embeds_1,
                                    return_dict=False
                                )[0]

                                uncond_model_output_1 = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=uncond_prompt_embeds_1,
                                    return_dict=False
                                )[0]

                                noise_est_1, predicted_variance = torch.split(model_output_1, image.shape[1], dim=1)
                                uncond_noise_est_1, _ = torch.split(uncond_model_output_1, image.shape[1], dim=1)

                                cfg_noise_est_1 = uncond_noise_est_1 + scale*(noise_est_1 - uncond_noise_est_1)
                                cfg_noise_est_1 = TF.gaussian_blur(cfg_noise_est_1, kernel_size=33, sigma=2)

                                model_output_2 = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=prompt_embeds_2,
                                    return_dict=False
                                )[0]

                                uncond_model_output_2 = stage_1.unet(
                                    image.half().to(device),
                                    t,
                                    encoder_hidden_states=uncond_prompt_embeds_2,
                                    return_dict=False
                                )[0]

                                noise_est_2, _ = torch.split(model_output_2, image.shape[1], dim=1)
                                uncond_noise_est_2, _ = torch.split(uncond_model_output_2, image.shape[1], dim=1)

                                cfg_noise_est_2 = uncond_noise_est_2 + scale*(noise_est_2 - uncond_noise_est_2)
                                cfg_noise_est_2 = cfg_noise_est_2 - TF.gaussian_blur(cfg_noise_est_2, kernel_size=33, sigma=2)


                                cfg_noise_est = cfg_noise_est_1 + cfg_noise_est_2

                                clean_t_step = (image - torch.sqrt(1-alpha_cumprod)*cfg_noise_est) / torch.sqrt(alpha_cumprod)
                                pred_prev_image = ((torch.sqrt(alpha_cumprod_prev)*beta)/(1-alpha_cumprod))*clean_t_step 
                                                    + ((torch.sqrt(alpha)*(1-alpha_cumprod_prev))/(1-alpha_cumprod))*image
                                pred_prev_image = add_variance(predicted_variance.to('cpu'), 
                                                               torch.tensor([t]), 
                                                               pred_prev_image.to('cpu'))

                                image = pred_prev_image.half().to(device)

                            clean = image.cpu().detach().numpy()

                        return clean
